AraujoRealty - Real Estate Platform

A full-stack web application designed for **Araújo Imóveis e Família**. The platform features a responsive public showcase for potential clients and an intuitive **Admin Dashboard** (CMS) for internal property management.

Key Features:

* **Public Showcase:** Clean and responsive UI for browsing available properties with detailed filters.
* **Admin Dashboard:** Secure authentication system allowing authorized users to manage listings.
* **CRUD Operations:** Full capability to Create, Read, Update, and Delete property entries.
* **Real-time Database:** Instant data syncing and image storage powered by Firebase.

Tech Stack:

* **Frontend Framework:** Next.js (React)
* **Styling:** Tailwind CSS
* **Backend & Database:** Firebase (Authentication, Firestore, Storage)
* **Language:** TypeScript
